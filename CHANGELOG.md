# Changelog

This file tracks repository-wide changes. Package releases are documented in each package's own changelog.

## Unreleased

- Added built-in English/Greek localization, shared adapter effects, fully customizable menu parts, Svelte head support, and top/inline positions.
- Made preference persistence best-effort so blocked storage never prevents an active DOM preference.
- Unified Astro and Svelte UI/effect contracts on the common Ooops UI part primitive.
- Added packed Astro/Svelte consumers with a shared Playwright parity contract, Axe checks, mobile/desktop position coverage, and visual captures.
- Matched the Ooops Suite accessibility SVG set, moved Reset beside Close, and made open panels fit the available viewport height.
- Tightened control-label line height, removed unnecessary bold emphasis, and included panel padding in its height limit so Greek mobile menus render without bottom overflow.
- Added shared atomic `classNames` parts, layout CSS variables, complete unstyled adapter examples, a headless sidebar/settings pattern, and documented Astro behavior attributes.

## 0.1.0

- Initial public release of the core, Astro, and Svelte accessibility packages.
