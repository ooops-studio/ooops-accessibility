# @ooopsstudio/accessibility-editor-manifests

Optional Ooops Editor manifests for the headless accessibility preferences and Astro components.

```sh
pnpm add @ooopsstudio/accessibility-editor-manifests
```

```ts
import {accessibilityAstroEditorManifest} from '@ooopsstudio/accessibility-editor-manifests'
```

The core accessibility runtime and Astro components remain usable without editor contracts. MIT licensed.
